# Задачи: цикли 

> [!IMPORTANT]
> За всяка задача се очаква да направите проверка за коректността на входа и хода на програмата!

## Задача 1 · Десетична ⇄ двоична

Напишете програма, която по подадено **16-битово** число `n` извежда на конзолата представянето му в двоична бройна система. Направете и обратната задача: по подадено `n` в двоична го принтирайте в десетична.

| Вход   | Изход              |
|--------|--------------------|
| `10`   | `1010`             |
| `-12`  | `1111111111110100` |
| `1010` | `10`               |

---

## Задача 2 · Позиция на цифра 

Да се напише програма, която по въведени от клавиатурата неотрицателно цяло число `x` и цифра `y` намира поредния номер на първото срещане на `y` в `x`.

> [!TIP]
> Броенето е **отдясно наляво** и започва от **1**. Внимавайте дали `y` фигурира в числото!

| Вход        | Изход |
|-------------|-------|
| `34215 4`   | `4`   |
| `5642641 4` | `2`   |

## Задача 10 · Разстояние по Хеминг

> [!NOTE]
> **Разстояние по Хеминг** е броят позиции в двоичния запис на две числа, в които те се различават.

| Вход  | Изход  |
|-------|-------|
| `1 4` | `2`   |

```
1 → 001
4 → 100
    ^  ^
```

## Задача 13 . Двоичен масив

Въведете произволно число n от конзолата (n < 64). След това въвеждайте числа в интервала [0,..,n] и ги записвайте побитово в променлива с размер 64 бита. Ако поредното въведено число е i, то бит на индекс i трябва да има стойност 1. Aко на входа бъде подадена стойност по-голяма от n или 63, да бъде изведен print на конзолата, съобщаващ за това. 

Продължете въвеждането до подаване на -1 като вход. След това отпечатайте всички елементи, които сте въвели досега.

```
Вход:
58
2 17 33 5 4 -1
Изход:
2 4 5 17 33


Вход:
19
2 5 4 27 -1
Изход:
Invalid value. Element was not added to bitset!
2 4 5
```

## Задача 14* . Генериране на подмножества 

Напишете програма, която прочита от конзолата цяло неотрицателно число n, след което принтира всички подмножества на дадено множество от n елемента (n <= 63). Като елементите ще са числата от 1 до n.

```
{ 2 }
{ 1 2 }
{ 3 }
{ 1 3 }
{ 2 3 }
{ 1 2 3 }

Изход:
{ }

#3 Пример

5

Изход:
{ }
{ 1 }
{ 2 }
{ 1 2 }
{ 3 }
{ 1 3 }
{ 2 3 }
{ 1 2 3 }
{ 4 }
{ 1 4 }
{ 2 4 }
{ 1 2 4 }
{ 3 4 }
{ 1 3 4 }
{ 2 3 4 }
{ 1 2 3 4 }
{ 5 }
{ 1 5 }
{ 2 5 }
{ 1 2 5 }
{ 3 5 }
{ 1 3 5 }
{ 2 3 5 }

{ 4 5 }
{ 1 4 5 }
{ 2 4 5 }
{ 1 2 4 5 }
{ 3 4 5 }
{ 1 3 4 5 }
{ 2 3 4 5 }
{ 1 2 3 4 5 }
```

> Разгледайте дали няма биекция между двоичните числа с n бита и подмножествата на n елемента?
