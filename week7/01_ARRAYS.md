# Масиви, що е то? 

Почти всяка програма работи не с една или две стойности, а с **много стойности от един и същи вид**: оценките на всички ученици в класа, температурите за всеки ден от месеца, пикселите на снимка, буквите в една дума...

За да пишем какъвто и да е смислен софтуер, ни трябва начин да **групираме такива данни заедно** и да работим с тях като с едно цяло.

Нека видим защо това е толкова важно с един съвсем прост пример.

---

## Задачата

> **Искаме да намерим и запазим първите пет прости числа.**

Напомняне: *просто* е число, по-голямо от 1, което се дели без остатък само на 1 и на себе си. Първите пет прости числа са **2, 3, 5, 7 и 11**.

Да приемем, че вече имаме готова функция `is_prime(n)`, която връща `1` (истина), ако `n` е просто, и `0` (лъжа), ако не е:

```c
int is_prime(int n)
{
    if (n < 2)
        return 0;

    for (int d = 2; d * d <= n; ++d)
    {
        if (n % d == 0)
            return 0; // намерихме делител → не е просто
    }

    return 1; // няма делители → просто е
}
```


## Как бихме го направили със сегашните си знания?

Засега знаем само как да създаваме отделни променливи. Затова единственото, което можем да направим, е да си заделим **пет отделни променливи** и да ги попълним една по една:

```c
int main(void)
{
    int p1, p2, p3, p4, p5;   // пет отделни променливи за пет числа

    int i = 2;

    // търсим първото просто число, започвайки от 2
    for (; !is_prime(i); ++i);
    p1 = i++;   // запазваме го и продължаваме от следващото число

    // търсим второто просто число
    for (; !is_prime(i); ++i);
    p2 = i++;

    // търсим третото просто число
    for (; !is_prime(i); ++i);
    p3 = i++;

    // ... и така нататък за p4 и p5

    return 0;
}
```

> 💡 **Как работи `for (; !is_prime(i); ++i);`?**
> Това е цикъл без тяло (забележете `;` накрая). Той просто увеличава `i`, докато `i` не стане просто число. Когато цикълът спре, в `i` стои търсеното число.

### Какъв е проблемът?

Кодът *работи*, но е изключително неудобен:

- 🔁 **Много повторение.** Едни и същи два реда копираме отново и отново. Ако открием грешка в тях, трябва да я поправим на пет места.
- 📈 **Не се мащабира.** Ами ако поискаме първите **100** прости числа? Или **10 000**? Ще пишем ли `p1`, `p2`, ..., `p10000` на ръка?
- 🚫 **Не можем да ги обходим с цикъл.** Ако после искаме да отпечатаме всичките пет числа, пак трябва да напишем пет отделни `printf`-а. Няма как да кажем „дай ми *k*-тата променлива“.

Накратко: пишем много код, а ние **не обичаме да пишем много код!**

## Какво всъщност бихме искали?

Идеалният вариант би бил да имаме **една-единствена променлива**, която побира **няколко стойности**, и да можем да достъпваме всяка от тях **по пореден номер**.

Тогава цялата задача може да се реши с един-единствен цикъл:

```c
int main(void)
{
    <нещо> primes;   // ❓ една променлива, която побира 5 числа

    int counter = 0; // колко прости числа сме намерили досега

    for (int i = 2; counter < 5; ++i)
    {
        if (is_prime(i))
        {
            // запазваме i като просто число с номер counter
            ++counter;
        }
    }

    return 0;
}
```

Забележете разликата:

| Със сегашните знания | Това, което искаме |
|---|---|
| 5 отделни променливи | 1 променлива |
| Код, копиран 5 пъти | Един цикъл |
| Трудно се променя броят | Променяме само числото `5` |
| Не може да се обходи с цикъл | Достъп по номер (индекс) |

Остават ни два въпроса:

1. **Какво да напишем на мястото на `<нещо>`?**
2. **Как да кажем „сложи `i` на позиция номер `counter`“?**

---

## Отговорът: масив!

Точно за това служат **масивите**.

> 📦 **Масивът** е поредица от елементи **от един и същи тип**, разположени **един след друг в паметта**, които имат **едно общо име** и се достъпват **по индекс** (пореден номер).

Ето решението:

```c
#include <stdio.h>

int is_prime(int n); // дефинирана по-горе

int main(void)
{
    int primes[5];   // масив от 5 цели числа

    int counter = 0;

    for (int i = 2; counter < 5; ++i)
    {
        if (is_prime(i))
        {
            primes[counter] = i; // записваме i на позиция counter
            ++counter;
        }
    }

    // отпечатваме всички намерени числа — пак с един цикъл!
    for (int k = 0; k < 5; ++k)
    {
        printf("primes[%d] = %d\n", k, primes[k]);
    }

    return 0;
}
```

Резултат:

```
primes[0] = 2
primes[1] = 3
primes[2] = 5
primes[3] = 7
primes[4] = 11
```

Ето как изглежда масивът `primes` в паметта:

```
 индекс:    [0]   [1]   [2]   [3]   [4]
          +-----+-----+-----+-----+-----+
 primes:  |  2  |  3  |  5  |  7  | 11  |
          +-----+-----+-----+-----+-----+
```

> ⚠️ **Важно:** индексите в C започват от **0**, а не от 1! Масив с 5 елемента има индекси от `0` до `4`. Опитът да се достъпи `primes[5]` е **грешка** (недефинирано поведение), защото такъв елемент няма, и компилаторът **няма** да ви предупреди за нея.

---

## Обобщение

- Когато имаме **много стойности от един и същи тип**, отделните променливи бързо стават неудобни.
- **Масивът** ни позволява да ги съберем под **едно име** и да ги достъпваме чрез **индекс**: `име[индекс]`.
- Индексите започват от **0** и стигат до **размер − 1**.
- Благодарение на индексите можем да обхождаме масив с **цикъл**, вместо да пишем един и същи код многократно.

В следващите части ще разгледаме подробно как се декларират и инициализират масиви, какво се случва с тях в паметта и защо `sizeof` понякога ни лъже.
