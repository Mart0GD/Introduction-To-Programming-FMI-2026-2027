# Указатели

Досега работихме с променливи и масиви, като винаги се обръщахме към тях **по име**. В тази тема ще се запознаем с **указателите**: механизъм, който позволява да достъпваме и променяме данни **индиректно**, чрез тяхното местоположение в паметта.

## Какво е указател?

Всяка променлива, дефинирана в програмата, заема **определено място в паметта**. Номерът на това място се нарича **адрес**. 

Всяка променлива се характеризира с три неща:

| Характеристика | Описание | Пример |
|---|---|---|
| **Име** | Идентификатор, чрез който се обръщаме към променливата в кода | `elem` |
| **Стойност** | Данните, записани в променливата | `5` |
| **Адрес** | Мястото в паметта, на което се намират данните | `0x7ffd5a3c` |

> **Указателят** е променлива, чиято стойност е **адрес на друга променлива**. Интуитивно указателя "указва", къде точно се намира променливата.

Указателят не съдържа самите данни, а само информация **къде** се намират те.

---

## Оператор `&`: вземане на адрес

Адресът на дадена променлива се получава чрез **оператора `&`** (адресиращ оператор):

<img width="600" alt="CopyQ NXPFtu" src="https://github.com/user-attachments/assets/602a779e-08b3-4086-8a8d-7290abb653b9" />

```c
int elem = 5;            // обикновена променлива със стойност 5
int *elem_ptr = &elem;   // указател към int, инициализиран с адреса на elem
```

Вторият ред се чете така: *„`elem_ptr` е указател към `int`, на който присвояваме адреса на `elem`“.* В резултат `elem_ptr` **сочи към** `elem`.

Адресите могат да бъдат отпечатани чрез спецификатора `%p`, като указателят се преобразува към `void *`:

```c
printf("Адрес на elem:          %p\n", (void *)&elem);
printf("Стойност на elem_ptr:   %p\n", (void *)elem_ptr);   // същият адрес
```

> [!NOTE]
> Адресите обикновено се изписват в **шестнадесетична** бройна система (например `0x7ffd5a3c`). Конкретните стойности се различават при всяко изпълнение на програмата.

---

## Оператор `*`: достъп до стойността

Указателят съдържа **единствено адреса** на `elem`, но **не и нейната стойност**. За да достъпим стойността, използваме **оператора `*`** (дереференциращ оператор). При разименуване се извършват следните стъпки:

1. взима се адресът, записан в указателя;
2. достъпва се паметта на този адрес;
3. прочитат се толкова байта, колкото е **размерът на типа, към който сочи указателят** (за `int *` това е `sizeof(int)`, обикновено 4 байта);
4. прочетените байтове се тълкуват като стойност от съответния тип.

```c
int elem = 5;
int *elem_ptr = &elem;

printf("%d\n", *elem_ptr);   // 5
```

Разименуваният указател може да се използва както за **четене**, така и за **запис**. Това позволява стойността на `elem` да бъде променена, без в израза да участва името ѝ.

### Двете значения на символа `*`

Символът `*` има различно значение в зависимост от контекста:

| Контекст | Пример | Значение |
|---|---|---|
| **Дефиниция** | `int *p;` | `p` е указател към `int` |
| **Израз** | `*p = 10;` | достъп до стойността на адреса, записан в `p` |

### Обобщение на операторите `&` и `*`

| Израз | Резултат | Стойност в примера |
|---|---|---|
| `elem` | стойността на `elem` | `5` |
| `&elem` | адресът на `elem` | напр. `0x7ffd5a3c` |
| `elem_ptr` | адресът, записан в указателя | `0x7ffd5a3c` |
| `*elem_ptr` | стойността на този адрес | `5` |
| `&elem_ptr` | адресът на **самия указател** | напр. `0x7ffd5a40` |

> [!NOTE]
> Операторите `&` и `*` са **взаимно обратни**: изразът `*&elem` е еквивалентен на `elem`.


## Типове указатели

Указател може да бъде дефиниран към всеки от разгледаните досега типове:

| Тип на стойността | Дефиниция на указател | Брой прочетени байтове при `*ptr` (обикновено) |
|---|---|---|
| `int`    | `int *ptr;`    | 4 |
| `float`  | `float *ptr;`  | 4 |
| `double` | `double *ptr;` | 8 |
| `char`   | `char *ptr;`   | 1 |

**Типът на указателя определя как се тълкува паметта, към която той сочи**: колко байта се прочитат и как те се преобразуват в стойност. Затова указател от тип `int *` трябва да сочи към `int`, указател от тип `double *` към `double` и т.н. При несъответствие на типовете се прочита грешен брой байтове и резултатът е некоректен.

> [!WARNING]
> **Размерът на самия указател не зависи от типа, към който сочи.**
>
> Указателите `int *`, `double *` и `char *` имат **еднакъв размер**, тъй като всички съхраняват адрес. Този размер се определя от **архитектурата**: на **32-битова** система указателите обикновено са **4 байта**, а на **64-битова** са **8 байта**. 
>
> ```c
> printf("%zu\n", sizeof(int *));     // 8 на 64-битова система
> printf("%zu\n", sizeof(double *));  // 8
> printf("%zu\n", sizeof(char *));    // 8
> ```

## Указатели и `const`

Ключовата дума `const` може да се комбинира с указатели по няколко начина. При указателите има **два обекта**, които могат да бъдат защитени от промяна:

- **стойността**, към която сочи указателят;
- **самият указател**, т.е. адресът, записан в него.

В зависимост от **позицията на `const` спрямо `*`** се получават четири възможни комбинации.

### 1. Указател към константа

```c
const int *p;     // или int const *p;
```

Указателят сочи към стойност, която **не може да бъде променяна чрез него**. Самият указател обаче **може** да бъде пренасочван към друг адрес.

```c
int a = 5;
int b = 10;

const int *p = &a;

printf("%d\n", *p);   // ✅ четене: 5
*p = 20;              // ❌ грешка при компилация: стойността е само за четене чрез p
p = &b;               // ✅ указателят може да бъде пренасочен
```

> [!IMPORTANT]
> Указателят с `const` **не прави самата променлива константна**. Той само забранява промяната ѝ **чрез този указател**.

Указателите с константност се използват най-често като **параметри на функции**, когато функцията трябва само да чете данни, без да ги променя:

```c
void print_array(const int *arr, int size)
{
    for (int i = 0; i < size; ++i)
    {
        printf("%d ", arr[i]);   // ✅ четене
        // arr[i] = 0;           // ❌ грешка при компилация
    }
}
```

Така дефиницията на функцията ясно показва, че подаденият масив **няма да бъде модифициран**, а компилаторът гарантира това.

### 2. Константен указател

```c
int *const p = &a;
```

Самият указател е константа: **адресът в него не може да се променя**, затова той **трябва да бъде инициализиран** при дефиницията си. Стойността, към която сочи, **може** да бъде променяна.

```c
int a = 5;
int b = 10;

int *const p = &a;

*p = 20;        // ✅ промяна на стойността: a вече е 20
p = &b;         // ❌ грешка при компилация: указателят е константен

int *const q;   // ❌ грешка: константен указател без инициализация
```

### 3. Константен указател към константа

```c
const int *const p = &a;
```

Комбинация от двата предходни случая: **нито стойността** може да бъде променяна чрез указателя, **нито самият указател** може да бъде пренасочен.

```c
int a = 5;
int b = 10;

const int *const p = &a;

printf("%d\n", *p);   // ✅ четене: 5
*p = 20;              // ❌ грешка: стойността е само за четене чрез p
p = &b;               // ❌ грешка: указателят е константен
```

### Сравнение

| Дефиниция | Наименование | Промяна на `*p` | Промяна на `p` |
|---|---|:---:|:---:|
| `int *p` | указател | ✅ | ✅ |
| `const int *p` | указател към константа | ❌ | ✅ |
| `int *const p` | константен указател | ✅ | ❌ |
| `const int *const p` | константен указател към константа | ❌ | ❌ |

### Правило за четене

Дефинициите с `const` и указатели се четат най-лесно **отдясно наляво**, като `*` се чете „указател към“:

| Дефиниция | Четене отдясно наляво |
|---|---|
| `const int *p // int const *p` | `p` е указател към `int`, който е `const` |
| `int *const p` | `p` е `const` указател към `int` |
| `const int *const p` | `p` е `const` указател към `int`, който е `const` |

Накратко:

- `const` **вляво** от `*` защитава **стойността**;
- `const` **вдясно** от `*` защитава **указателя**.

### Преобразувания между указатели

- Преобразуването от `int *` към `const int *` е **позволено и неявно**, тъй като се **добавя** ограничение:

    ```c
    int a = 5;
    int *p = &a;
    const int *cp = p;   // ✅
    ```

- Обратното преобразуване, от `const int *` към `int *`, **премахва** ограничение и компилаторът издава предупреждение или грешка:

    ```c
    const int *cp = &a;
    int *p = cp;         // ⚠️ предупреждение: discards 'const' qualifier
    ```

> [!WARNING]
> Промяната на константна стойност през явно преобразуван указател е недефинирано поведение!
> ```c
> const int x = 5;
> int *p = (int *)&x;
> *p = 10;             // ❌ недефинирано поведение
> ```

## Невалидни указатели

Операторът `*` достъпва адреса, записан в указателя, **без никаква проверка**. Езикът C не гарантира, че на този адрес се намира валидна променлива, затова дереференцирането на невалиден указател е **недефинирано поведение**. Програмата може да прекрати работа (**segmentation fault**), да прочете произволни данни или привидно да работи коректно.

```c
int *p;          // ❌ неинициализиран указател: съдържа произволен адрес
*p = 10;         // недефинирано поведение

int *q = NULL;   // ✅ NULL означава, че указателят не сочи към валиден обект
if (q != NULL)
{
    *q = 10;     // разименуване само след проверка
}
```

> [!TIP]
> Указателите трябва **винаги** да бъдат инициализирани с адреса на съществуваща променлива или с `NULL`. Така валидността им може да бъде проверена преди употреба.

## Обобщение

- **Указателят** е променлива, чиято стойност е **адрес** на друга променлива.
- `&x` връща **адреса** на `x`.
- `*p` осигурява достъп до **стойността** на адреса, записан в `p`, както за четене, така и за запис.
- Типът на указателя определя **как се тълкува** паметта, към която сочи.
- Всички указатели имат **еднакъв размер**, определен от архитектурата.
- `const int *p`: стойността **не може** да бъде променяна чрез `p`.
- `int *const p`: указателят **не може** да бъде пренасочван.
- `const int *const p`: не може да се променя **нито едното, нито другото**.
- Неинициализиран указател или `NULL` указател **не трябва** да бъде разименуван.

Указателите позволяват индиректен достъп до данни чрез техния адрес. Този механизъм е основата за работата с масиви във функции, която ще бъде разгледана в следващата тема.
