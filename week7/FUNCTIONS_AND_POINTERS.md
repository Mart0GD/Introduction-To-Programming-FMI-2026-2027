# Подаване на аргументи на функции

Сега ще разгледаме какво се случва с променливите, когато ги подаваме като аргументи на функции, и как чрез **указателите** функцията може да промени променлива, дефинирана извън нея.

## Подаване по стойност

По подразбиране аргументите в **C** се подават **по стойност** (*pass by value*). Това означава, че при извикване на функцията **стойността** на всеки аргумент се **копира** в съответния параметър, който се намира в **стековата рамка** (*stack frame*) на извиканата функция.

Функцията работи **единствено с копието**. Всички промени, които тя извършва върху параметрите си, **не се отразяват** на оригиналните променливи в извикващата функция.

В много случаи това е желано поведение, тъй като функцията не може по невнимание да промени данни, които не ѝ принадлежат. Нека обаче разгледаме пример, в който то е проблем.

### Пример

Искаме функция, която увеличава стойността на дадена променлива с 1, ако тя е четна:

```c
#include <stdio.h>

void add_one_if_even(int elem)
{
    if (elem % 2 == 0)
    {
        elem++;   // променяме КОПИЕТО
    }
}

int main(void)
{
    int elem = 2;

    add_one_if_even(elem);

    printf("%d\n", elem);   // очакваме 3, но отпечатва 2
    return 0;
}
```

Желаният ефект **не се постига**, тъй като `elem` се подава по стойност. Функцията `add_one_if_even` получава **копие** на `elem` и увеличава него, а не оригинала.

Адресите са **различни**, т.е. става дума за **две напълно отделни променливи**, които само имат еднакво име:

| Променлива | Стекова рамка | Начална стойност | Стойност след извикването |
|---|---|:---:|:---:|
| `elem` в `main` | на `main` | `2` | `2` |
| `elem` в `add_one_if_even` | на `add_one_if_even` | `2` (копие) | `3` |

Параметърът `elem` на `add_one_if_even` съществува **единствено в стековата рамка на тази функция**. Когато функцията приключи, рамката ѝ се освобождава и параметърът престава да съществува, а заедно с него се губят и всички извършени върху него промени.

## Подаване по адрес

Тук използваме знанията си за **указатели**. Вместо да подаваме **стойността** на променливата, подаваме нейния **адрес**. Параметърът на функцията вече е **указател**, който сочи към оригиналната променлива.

Чрез **оператора за дереференциране `*`** функцията получава достъп до стойността на оригинала и може да я променя.

```c
#include <stdio.h>

void add_one_if_even(int *elem)
{
    if (*elem % 2 == 0)
    {
        (*elem)++;   // променяме ОРИГИНАЛА чрез указателя
    }
}

int main(void)
{
    int elem = 2;

    add_one_if_even(&elem);   // подаваме адреса на elem

    printf("%d\n", elem);     // отпечатва 3
    return 0;
}
```

**Промените спрямо предходния пример**

| Място | По стойност | По адрес |
|---|---|---|
| Параметър | `int elem` | `int *elem` |
| Използване във функцията | `elem` | `*elem` |
| Извикване | `add_one_if_even(elem)` | `add_one_if_even(&elem)` |

> [!WARNING]
> Скобите в `(*elem)++` са **задължителни**. Без тях `*elem++` увеличава **указателя**, а не стойността, към която сочи.

Сега поведението е очакваното. Функцията получава **адреса** на оригиналната променлива и чрез дереференциране може да променя стойността ѝ, макар тя да се намира **извън собствената ѝ стекова рамка**.

Функции, които променят състоянието на програмата извън собствената си стекова рамка, се наричат **функции със страничен ефект** (*side effect*). Към тях спадат и функции, които променят глобални променливи или извършват вход/изход (например `printf`).

> [!IMPORTANT]
> **В C всъщност съществува само подаване по стойност.** При „подаване по адрес“ отново се копира стойност, но този път това е **адресът** на променливата. Параметърът `elem` в `add_one_if_even` е **отделен указател**, който съдържа **копие** на адреса на `elem` от `main`. Затова пренасочването на самия указател във функцията (например `elem = NULL;`) **не засяга** нищо извън нея. Засяга го само промяната на стойността **през** указателя (`*elem = ...`).


## Класически пример: размяна на две стойности

Типичен пример, при който подаването по адрес е **необходимо**, е функция, която разменя стойностите на две променливи.

Подаване по стойност (**не работи**):

```c
void swap(int a, int b)
{
    int tmp = a;
    a = b;
    b = tmp;      // разменят се само копията
}
```

Подаване по адрес (**работи**):

```c
#include <stdio.h>

void swap(int *a, int *b)
{
    int tmp = *a;
    *a = *b;
    *b = tmp;     // разменят се оригиналите
}

int main(void)
{
    int x = 1;
    int y = 2;

    swap(&x, &y);

    printf("x = %d, y = %d\n", x, y);   // x = 2, y = 1
    return 0;
}
```

## Чести грешки

### Разименуване на `NULL`

Ако функцията приема указател, извикващият може да подаде `NULL`. Ако е възможно това да се случи, указателят трябва да бъде проверен преди разименуване:

```c
void add_one_if_even(int *elem)
{
    if (elem == NULL)
    {
        return;
    }

    if (*elem % 2 == 0)
    {
        (*elem)++;
    }
}
```

### Връщане на адрес на локална променлива

Локалните променливи престават да съществуват след края на функцията, затова **никога** не трябва да се връща техният адрес:

```c
int *create_number(void)
{
    int number = 42;
    return &number;   // number ще бъде унищожена след return
}

int main(void)
{
    int *p = create_number();
    printf("%d\n", *p);   // недефинирано поведение
    return 0;
}
```

Указателят `p` сочи към памет, която вече **не принадлежи** на никоя променлива. Такъв указател се нарича **висящ указател** (*dangling pointer*).

## Сравнение

| | По стойност | По адрес |
|---|---|---|
| Какво се копира | стойността на променливата | адресът на променливата |
| Тип на параметъра | `int` | `int *` |
| Аргумент при извикване | `x` | `&x` |
| Може ли функцията да промени оригинала | Не | Да |

## Обобщение

- По подразбиране аргументите се подават **по стойност**: функцията работи с **копие** и не може да промени оригинала.
- Параметрите съществуват само в **стековата рамка** на функцията и се унищожават при нейното приключване.
- При **подаване по адрес** функцията получава **указател** към оригинала и чрез `*` може да го променя.
- Подаването по адрес също е подаване по стойност, но се копира **адресът**.
- Функциите, които променят данни извън своята стекова рамка, имат **страничен ефект**.
- Ако функцията само чете данните, параметърът трябва да е `const` указател.
- **Никога** не връщайте адрес на локална променлива.
