# Вход и изход

Когато искаме да работим с външни данни, било то файл или вход от конзолата, езикът **C** ни предоставя голям набор от инструменти. Тук ще разгледаме основните от тях. Няма да ги изчерпим напълно, тъй като обемът им излиза извън рамките на курса.

## `<stdio.h>`

За да получим достъп до стандартните функции за вход и изход, трябва да включим заглавния файл `stdio.h` (**st**andar**d** **i**nput and **o**utput). Това става с предпроцесорната директива `#include <име на файл>`:

```c
#include <stdio.h>

int main(void)
{
    /* ... */
    return 0;
}
```

> **Важно:** Файлът `stdio.h` съдържа само декларациите на функциите и дефинициите на макросите. Истинският им код се намира в стандартната C библиотека (libc), която е на вашата файлова система. Тя се свързва с програмата при компилиране, а при динамично свързване се зарежда при стартирането ѝ.

## Потоци: що е то?

При стартирането на всяка програма операционната система ѝ предоставя три потока за работа:

* `stdin`: стандартен поток за вход;
* `stdout`: стандартен поток за изход;
* `stderr`: стандартен поток за грешки.

По подразбиране `stdin` получава входа си от клавиатурата, а `stdout` и `stderr` извеждат на конзолата (терминала).

> **Чест проблем:** Потокът `stdout` е буфериран. Когато пише в терминал, буферът се изпразва при всеки нов ред или в края на програмата. Ако понякога изходът ви не се появява веднага, не се плашете: вероятно просто не сте сложили `\n`. Можете и да го изпратите принудително с `fflush(stdout);`.

## Вход и изход символ по символ

Когато искаме да прочетем или да запишем един символ, използваме следните функции:

| Функция | Действие |
| :--- | :--- |
| `getchar()` | чете символ от `stdin` |
| `getc(fp)` / `fgetc(fp)` | чете символ от поток |
| `putchar(c)` | пише символ в `stdout` |
| `putc(c, fp)` / `fputc(c, fp)` | пише символ в поток |
| `ungetc(c, fp)` | „връща“ прочетен символ обратно в потока |

Когато четем символи, пазим резултата в `int`, а не в `char`. Причината е стойността `EOF` (End Of File), която функциите връщат, когато няма повече данни. Тя е отрицателна (обикновено `-1`) и не е символ от файла, а сигнал за край. Прочетените символи са със стойности от 0 до 255, а заедно с `EOF` стават 257 възможни стойности, които не могат да се поберат в `char`. Освен това не е гарантирано дали `char` е със знак или без. Затова **когато четете символи, използвайте `int`!**

## Форматиран изход: `printf`

На пръв поглед изходът в **C** изглежда плашещ и не прилича на този в другите езици за програмиране. Тук имаме семейство от функции `printf`, като `f` идва от *formatted* (форматиран).

| Функция | Действие |
| :--- | :--- |
| `printf(формат, аргументи...)` | пише в `stdout` |
| `fprintf(поток, формат, аргументи...)` | пише в произволен поток |

### Спецификатори

Най-съществената разлика спрямо повечето езици за програмиране са спецификаторите. Те започват със знака `%` и указват как да се изведе съответният аргумент.

Структурата на един спецификатор е:

```
%[флагове][ширина][.точност][дължина]тип
```

#### Типове

**Цели числа**

| Спецификатор | Тип | Пример |
| :--- | :--- | :--- |
| `%hhd`, `%hhi` | `signed char` като число | `-42` |
| `%hhu` | `unsigned char` като число | `42` |
| `%hd`, `%hi` | `short` | `-42` |
| `%hu` | `unsigned short` | `42` |
| `%d`, `%i` | `int` | `-42` |
| `%u` | `unsigned int` | `42` |
| `%o`, `%x`, `%X` | `unsigned int`, осмично / шестнадесетично | `52` / `2a` / `2A` |
| `%ld`, `%li` | `long` | `-42` |
| `%lu` | `unsigned long` | `42` |
| `%lld`, `%lli` | `long long` | `-42` |
| `%llu` | `unsigned long long` | `42` |
| `%zu` | `size_t` | `42` |

**Числа с плаваща запетая**

| Спецификатор | Тип | Пример |
| :--- | :--- | :--- |
| `%f`, `%F` | `double`, а също и `float` | `3.141593` |
| `%lf`, `%lF` | `double`, същото като `%f` | `3.141593` |
| `%e`, `%E` | `double`, научен запис | `3.141593e+00` |
| `%a`, `%A` | `double`, шестнадесетичен запис | `0x1.921fb54442d18p+1` |
| `%Lf`, `%LF` | `long double` | `3.141593` |
| `%Le`, `%LE` | `long double`, научен запис | `3.141593e+00` |
| `%La`, `%LA` | `long double`, шестнадесетичен запис | `0xc.90fdaa22168c235p-2` |

**Символи, низове и други**

| Спецификатор | Тип | Пример |
| :--- | :--- | :--- |
| `%c` | `int`, извежда се като символ | `A` |
| `%s` | низ | `hello` |
| `%p` | адрес | `0x7ffd5e8c3a4c` |
| `%%` | буквален знак `%` | `%` |

Както виждате, спецификаторите са много, но няма нужда да ги помните всичките. Докато решавате задачи, ще научите тези за основните типове в езика. Останалите винаги можете да намерите в таблицата тук или онлайн.

#### Флагове, ширина и точност

Освен типа можем да зададем и други параметри на форматирането, като ширина на полето, подравняване, брой знаци след десетичната точка и т.н.

```c
#include <stdio.h>

int main(void)
{
    printf("[%5d]\n", 42);        // [   42]   ширина 5, подравнено вдясно
    printf("[%-5d]\n", 42);       // [42   ]   '-' подравнява вляво
    printf("[%05d]\n", 42);       // [00042]   '0' запълва с нули
    printf("[%+d]\n", 42);        // [+42]     '+' винаги показва знак
    printf("[% d]\n", 42);        // [ 42]     интервал вместо '+'
    printf("[%#x]\n", 255);       // [0xff]    '#' добавя префикс
    printf("[%.3f]\n", 3.14159);  // [3.142]   3 знака след десетичната точка
    printf("[%.3s]\n", "abcdef"); // [abc]     за низ: най-много 3 символа
    printf("[%*d]\n", 6, 42);     // [    42]  ширината идва от аргумент

    return 0;
}
```

Ако ви е интересно откъде идват тези спецификатори, можете да прочетете за историята на [`printf`](https://en.wikipedia.org/wiki/Printf).

## Форматиран вход: `scanf`

Четенето в **C** следва принципи, подобни на тези при `printf`. Тук работим със семейството функции `scanf`, където `f` отново идва от *formatted*.

| Функция | Действие |
| :--- | :--- |
| `scanf(формат, адреси...)` | чете от `stdin` |
| `fscanf(поток, формат, адреси...)` | чете от произволен поток |
| `sscanf(низ, формат, адреси...)` | чете от подадения низ |

> **Внимание:** Спецификаторите за типове са същите като при `printf`, с едно важно изключение: тук `%f` означава `float`, а за `double` се използва `%lf`.

### Четене по адрес

При четене аргументите се подават със знака за взимане на адрес `&`. Подробно ще разберем защо е така по-напред в курса.

```c
#include <stdio.h>

int main(void)
{
    unsigned number;
    scanf("%u", &number);

    return 0;
}
```

### Как `scanf` съпоставя входа

`scanf` обхожда форматния низ отляво надясно и съпоставя всяка част с входа по селдния начин:

| Във формата | Какво очаква във входа |
| :--- | :--- |
| спецификатор, напр. `%d` | стойност от съответния тип; повечето спецификатори прескачат водещите празни символи |
| празен символ: интервал, `\n`, `\t` | произволен брой празни символи, включително нула |
| всеки друг символ, напр. `-` | точно същия символ |

Ако някой символ не съвпадне, четенето спира веднага, а несъвпадналият символ остава непрочетен във входа.

```c
#include <stdio.h>

int main(void)
{
    unsigned n1, n2, n3;
    scanf("%u-%u-%u", &n1, &n2, &n3);

    /*
     *  Очакваме три числа, разделени с тире:
     *
     *  1-2-3     --> успешно
     *  12-345-6  --> успешно, %u чете цели числа
     *  1- 2-3    --> успешно, %u прескача интервала
     *  1 2-3     --> грешно, прочита се само n1
     */

    return 0;
}
```

### Какво връща `scanf`

`scanf` връща броя на **успешно прочетените и записани** стойности. Ако входът свърши, преди да е прочетено каквото и да е, връща `EOF`. Това е най-лесният начин да проверим дали входът е бил правилен:

```c
#include <stdio.h>

int main(void)
{
    unsigned n1, n2, n3;
    int res = scanf("%u-%u-%u", &n1, &n2, &n3);

    printf("Прочетох %d аргумента от конзолата!", res);
    return 0;
}
```

### Класическият капан: `%c` и новият ред

Повечето спецификатори прескачат водещите празни символи, включително знакът за нов ред. `%c` обаче **не го прави**, защото `\n` също е символ и понякога искаме да го прочетем. Затова, ако прочетем символ, след като вече сме прочели нещо друго, `scanf` ще вземе останалия от предишния ред `\n`:

```c
#include <stdio.h>

int main(void)
{
    int n;
    char c;

    scanf("%d", &n);  // потребителят пише "5" и Enter: прочита се 5, '\n' остава
    scanf("%c", &c);  // веднага прочита останалия '\n', без да чака потребителя!

    return 0;
}
```

**Решение:** слагаме интервал пред `%c`. Както видяхме по-горе, празен символ във формата прескача всички празни символи във входа, включително `\n`:

```c
scanf("%d", &n);
scanf(" %c", &c);  // интервалът прескача '\n', после се чете истинският символ
```
