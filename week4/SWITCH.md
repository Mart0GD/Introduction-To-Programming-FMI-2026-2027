# Switch оператор 

Изчислява код спрямо подаден интегрален (цяло число) аргумент. Може да изпълни както едно конкретно парче код така и няколко!

Синтаксис:

```.c
switch (<expression>)
{
    case <constant expression> : <<statement>> <<break;>>
    case <constant expression> : <<statement>> <<break;>>

    (...)

    default: <<statement>>
}
```

Където:

*  `expression` е израз изчисляващ се до интегрален тип (цяло число)
*  `constant expression` е константна интегрална стойност.
*  В `default` отиват всички случай без дефинирана от нас логика.  
*  <<>> - незадължителна част
*  <> - задължителна част

### Обяснение 

Операторът може да има неопределен брой от случай `case`, докато всички от тях са константни и уникални. От друга страна можем да имаме най-много един `default`. 

Имаме следните случай:

* Ако `expression` се изчисли до съществуващ `case`, то тогава се изпълнява неговият statement.
* Ако `expression` се изчисли до стойност, която не се покрива от `case`, но има `default`, то контролът се прехвърля към него.
* Ако `expression` се изчисли до стойност, която не се покрива от `case`, но няма `default`, то оператотър се порпуска изцяло.

**Fall through**

При достигнат `break` се напуска switch оператора. Ако няма такъв, то изпълнението продължава към следващия случай докато не се достигне края на блока на оператора.

```.c
#include "stdio.h"

int main(void)
{
    int a = 5;
    int sum = 0;
    switch(a)
    {
        case 5: sum += 5;
        case 4: sum += 4;
        case 3: sum += 3;
        case 2: sum += 2;
        case 1: sum += 1;
        default: sum += 100;
    };

    printf("%d", sum); // --> 115
    return 0;
}
```

**Област на действие**

Важно е да знаете, че всички променливи в `switch` блок споделят една и съща област на действие. Ако искате две променливи с един и същи идентификатор трябва да добавите блок към израза.

Пример:

```.c
switch(n)
{
    case 1:
      int a = 4;
      int b = 5;
      int sum = a + b;
    break;

    case 2:
      int a = 10;       // Error: вече има променлива с идентификатор "a" 
      int b = 10;       // Error: вече има променлива с идентификатор "b" 
      int sum = a * b;  // Error: вече има променлива с идентификатор "sum" 
    break;

    default: break;
}

// В такъв случай пишем
switch(n)
{
    case 1:
    {
      int a = 4;
      int b = 5;
      int sum = a + b;
    } break;

    case 2:
    {
      // Вече са отделни блокове, нямаме грешки 
      int a = 10;       
      int b = 10;       
      int sum = a * b;  
    } break;

    default: break;
}
```

### Как работи switch?

Може би сега се питате - "Но как работи switch отдолу, как отива на правилния код?". За целта ще ви демонстрирам една функционалност на езика C (в частност и C++).

**Labels**

Това са маркери, които много наподобяват начина на екзекутиране на асемблерен код. Пишат се по следния начин: 

`label_name: <statement>;`. 

Тяхната идея е да можем да изпълним парче код където и да се намираме. Използването им не се препоръчва директно, тъй като най-често води до лош и нечетим код.

Можем да ги използваме по следния начин:

```.c
#include "stdio.h"

int main(void)
{
read_again:; // маркер без израз, служи само за скок

    int n;
    scanf("%d", &n);  

    // Искаме да прочетем правилна стойност
    if(n < 10) goto read_again;

    return 0;
}
```

### Обяснение

Ако стойността на `n` е по-малка от 10 се връщаме обратно в началото на main функцията и четем отново стойността на променливата. Примерът няма практическа стойност, но показва как можем да се движим в кода.

## Switch с goto 

```.c
#include <stdio.h>

int main(void)
{
    int n;
    scanf("%d", &n);

    if (n == 1) goto case1;
    if (n == 2) goto case2;
    if (n == 3) goto case3;
    goto default_;          // нито един case не съвпадна

case1:
    puts("Inside case 1");
    goto end;               // break;

case2:
    puts("Inside case 2");
    goto end;               // break;

case3:
    puts("Inside case 3");
    goto end;               // break;

default_:
    puts("Inside default");
    /* последният етикет няма нужда от goto end */

end:
    return 0;
```
