## Област на действие 

Всеки един идентификатор в програма написана на **C** е видим (може да се обърнем към него) само в някаква непрекъсната част от кода. Тази част ще наричаме **област на действие**.

В **C** различаваме 4 вида област на действие:

*  Block scope
*  File  scope
*  Function scope
*  Function prototype scope

Два идентификатора в едина и съща област на действие могат да сочат и различни данни само ако се намират в различни **наименувани области\***.

> Наименувана област - областта на действие на енумерации (enums), структури (structs), unions (обединения) и маркери (labels).

### Вложени области на действие (Nested scopes)

Ако можем да достъпим едновременно два различни обекта, които споделят идентификатор (наименувани са еднакво) и са в едно и също наименувано пространтсво, то тогава имаме вложени области на действе. 

Обектът във вложената област ще скрие този от горната:

```.c
#include "stdio.h"

// File namespace - всичко е в наименуваното пространтво на файла 

int a = 5; // област на действие на a от файла (file scope)

int main(void)
{   // влизаме в блока на main (това е вложена област във файловата област) 

    printf("%d", a); // принтира a от file scope, тъй като няма друго (file scope a)

    /*
    *  Имаме две "a"-та, но в различни блокове.
    *  Това значи, че новото "a" скрива старото.
    */
    int a = 100;

    printf("%d", a); // принтира 100 (main scope a)

    {   // вложена област на действие в main

        /*
        *  Имаме три "a"-та, но в различни блокове.
        *  Новото "a" отново скрива старото
        */
        int a = 200; // От тук нататък вече е областта на действие на вложеното a (nested a)

        printf("%d", a); // принтира 200 (nested scope a)
    }

    return 0;
}
```

### Блокови области (Block scopes)

Това са областите на действие на всички съставни оператори - if,else,switch,while,for,do/while и функции. 

```.c
int main(void)  
{  // започва блока на функцията main

    int n = 0;   // "n" е част от блока на функцията main 
    // int n = 2; // грешка: не можем да дефинираме две промеливи с един и същи идентификатор в блока

    if(n > 10)
    {
        int n = 100;      // област на локалната променлива "n"
        printf("%d", n);  // принтира 100 
    }  // свършва блока на "if"
   
    // Отново е в действие "n", дефинирано във функцията
     printf("%d\n", n); // 0

} // край на main

// Област на действие на файла 

int a = n; // Грешка: n вече не е дефинирано никъде във файла областта 
```

### Файлова област (File scope)

Това са всички идентификатори, които не са в блокове и не са параметри на функции. Те могат да се дефинират от началото до края на **translation unit-а** 

> translation unit - за сега считайте, че това е целият код с всички #include файлове добавени!

```.c
// Започва File scope 
int i; // част от file scope-a (наричаме ги "глобални променливи")

int main(void)
{
    i = 2;
    printf("%d", i); // принтира се 2
}
```
