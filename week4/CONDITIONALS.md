# Условният оператор if

**if** е оператор, контролиращ пътя на изпълнение на една програма. В С **if** позволява обработката на даден блок от код, когато е удоволетворено дадено условие.

Ако **expression** има стойност различна от нула, то условието ще е изпълнено.

```c
if (test_statement)
{
-//-
}
```

Ако искаме да обработим и случаят, когато условието не е изпълнено, ще добавим и **else** клауза.

```c
if (test_statement)
{
-//-
}
else
{
-//-
}
```

### Особеност при работа с if

Фигурните скоби `{}` не са задължителни. След условен оператор следва някакъв израз, той може да бъде както едноредов така и блок от код, който трябва да се изпълни, когато условието е удоволетворено.

#### Пример: следните две if-клаузи са еквивалентни

```c
int myVar = 1;
if (myVar)
printf("Entered if-clause\n");
```

```c
int myVar = 1;
if (myVar)
{
    printf("Entered if-clause\n");
}
```

### Вложени if-клаузи

#### Пример 1:

Както всяка една блокова конструкция и `if/else` клаузите могат да се влагат. 

<p>

```c
if (horsePower > 200)
    if (isDiesel == 1)
        tax *= 1.5f;
    else
        tax *= 1.25f;
else
    tax *= 1.06f;
```
</p>

#### Пример 2:

Много е важно да знаете, че `else` винаги се асоциира към най-близкия if, така че за четимост на кода е добре тук да сложим къдрави скоби `{}` за да укажем началото и края на блока.

```c
if (gradeEntry > 4) 
{
    if (gradeMidtrm >= 4)
        isTakingFinals = 1;
}
else
  isTakingFinals = 0;
```

### Вериги от If клаузи

Тъй като вече се запознахме с условния оператор **if**, то вече можем да осъществим по-сложни конструкции.

Искаме потребител на нашата програма да въведе ден, месец и година. После искаме да проверим дали въведените от него числа са с валидни стойности. 

```c
#include <stdio.h>

int main(void)
{
    unsigned day, month, year;
    
    printf("Enter a day in the following order DD/MM/YY\n");
    scanf("%u %u %u", &day, &month, & year);
    
    if (day == 0 || day > 31)
    {
        printf("Invalid day!\n");
        exit(-1);
    }
    if (month == 0 || month > 12)
    {
        printf("Invalid month!\n");
        exit(-1);
    }
    if (year < 0 || year > 2025)
    {
        printf("Invalid year\n");
        exit(-1);
    }
    
    return 0;

}
```

> [!Note]
> Ако и трите условия са изпълнени, то ще влезем и в трите if блока. Тогава как да моделираме ситуации, в които искаме да се изпълни тялото на точно един условен оператор?

## Else/if Ladders

За да демонстрираме поредица от логически проверки, от които да се изпълни само едно ще напишем следната програма - четем от конзолата оценка от изпита по линейна алгебра на студент във **ФМИ** и отпечатваме съответната му реакция. 

```c
int main()
{
    unsigned grade;
    
    printf("Каква оценка изкара по линейна алгебра на изпита?\n");
    scanf("%u", &grade);
    
    if (grade == 2) 
    {
        printf("Догодина пак\n");
    }
    else if (grade == 3)
    {
        printf("Най-хубавата оценка!\n");
    }
    else if (grade == 4)
    {
        printf("Как?\n");
    }
    else if (grade == 5)
    {
        printf("Купувам шампанско\n");
    }
    else if (grade == 6)
    {
        printf("Нещо се е объркал Божилов\n");
    }
    else 
        printf("Ква е тая оценка??\n");
    
    return 0;
}
```
