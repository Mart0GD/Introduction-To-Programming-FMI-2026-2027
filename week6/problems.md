> 1) За всяка задача, разделяйте до колкото можете логиката по функции!
> 2) Навсякъде където е нужно, да се валидира входа!

## Задача 1 - `Обратно число`

Напишете функция, която приема неотрицателно число n и връща обърнатото число.

```
Вход: 213
Изход: 312

Вход: 3144
Изход: 4413
```

## Задача 2 - `Коректна дата`

Да се напише програма, която проверява дали дата, зададена в следния формат: dd.mm.yyyy е коректна. 

```
Вход: 11.12.2001
Изход: Correct

Вход: 31.11.2026
Изход: Not correct 
```

## Задача 3 - `Суфикс на число`

Напишете функция, която приема неотрицателни числа n и k и връща дали k е суфикс на n.

>[!TIP]
> Суфикс наричаме последните последователни цифри. Един суфикс на `234` е `234`, `34`, но не и `3`.

```
Вход:  9812 12
Изход: Yes

Вход:  9817 98
Изход: No
```

## Задача 4 - `Префикс на число`

Напишете функция, която приема неотрицателни числа n и k и връща дали k е префикс на n.

>[!TIP]
> Префикс наричаме първите последователни цифри. Един префикс на `234` е `234`, също така и `23`, но не и `34`.

```
Вход:  9812 98
Изход: Yes

Вход:  9817 1
Изход: No
```

## Задача 5 - `Инфикс на число`

Напишете функция, която приема неотрицателни числа n и k и връща дали k е инфикс на n.

>[!TIP]
> Инфикс е подчисло в контекста на задачата. Инфикс на 234512 е: `23`, `4`, `45`, `12`, но не и `41`.

```
Вход:  9812 98
Изход: Yes

Вход:  981127 12
Изход: Yes

Вход:  911127 912
Изход: No
```

## Задача 6 - `Най-дълъг общ префикс/суфикс`

Да се дефинира функция, която намира дължината на най-дългия общ префикс/суфикс на два числа.

```
Вход: 1231 1287
Изход:   2   /    0
      (Prefix)  (Suffix)


Вход: 1231 122131
Изход:   2   /    2
      (Prefix)  (Suffix)
```

## Задача 7 - `Конкатенация на числа`

Конкатенация на две естествени числа n и k наричаме числото, което се получава като към цифрите на n "се долепят" към цифрите на k. Напишете функция, която приема две цели положителни числа n и k и връща тяхната конкатенация.


> [!TIP]
> Бонус: проверете дали след конкатенация, новото число е палиндром.

```
Вход: 213 19
Изход: 21319 (Not a palindrome!)

Вход: 35 53
Изход: 3553 (Palindrome!)
```

## Задача 8 - `Комбинаторен калкулатор`

Напишете програма, която прочита букви (команди) докато не прочете буквата 'E' и тогава прекратява действието си. Програмата ще се налага да поддържа следните команди:

P -> изисква допълнителен вход цяло число n и пресмята пермутацията на n.
V -> изисква допълнителен вход 2 цели числа n и k и пресмята колко на брой са вариациите на n елемента на k позиции (без повторения).
C -> изисква допълнителен вход 2 цели числа n и k и пресмята колко на брой са комбинациите на n елемента на k пзоции (без потоврения).
E -> край на програмата.
Друг вход -> принтира съобщение за невалиден вход и изисква нов вход "Invalid command input!"

> 0 <= k <= n <= 20

```
#1 Пример
Вход:
P 5
V 5 2
C 5 2
E

Изход:
P(5) = 120
V(5, 2) = 20
C(5, 2) = 10

#2 Пример
Вход:
P 18
V 2 5
V 25 2
B
5
E

Изход:
P(18) = 6402373705728000
Invalid number input!
Invalid number input!
Invalid command input!
Invalid command input!
```

## Задача 9 - `Прости инфикси`

Да се напише функция, която приема цяло положително число n и отпечатва всички инфикси на n, които са прости, като:

* Всяко число е инфикс на себе си;
* Отпечатайте всички инфиски, дори тези, които се повтарят;

```
Вход: 876492
Изход: 7, 2, 7649, 87649
```

## Задача 10 - `Брой различни прости делители`

Напишете програма, която прочита цяло положително число и принтира броя на различните му прости делители. Създайте и използвайте функция countDistinctPrimeDivisors, която приема цяло число като аргумент и връща броя на различните прости делители на това число.

```
Вход: 15
Изход: 2 -> 3 и 5

Вход: 17
Изход: 1 -> просто число 

Вход: 1
Изход: 0 -> няма
```

## Задача 11 - `Съседи близнаци`

Напишете програма, която прочита 2 цели числа start и end и принтира всички числа в интервала [start, end], които имат еднакви съседни цифри 

(примерни числа: 11, 22, 877, 2122).

```
Вход: 1 30
Изход: 11, 22

Вход: 870 880
Изход: 877, 880
```

## Задача 12 - `Водещи нули`

Напишете програма с функция, която прочита цяло число и принтира на конзолата броят на нулевите битове преди най-младшата единица.

```
Вход: 40
Изход: 3

Обяснение: 40(10) = 101000(2) | Имаме три нули преди най-младшата единица
```

## Задача 13 - `Най-дълга растяща редица`

Напишете функция, която приема число n и връща дължината на най-дългата поредица от последователни растящи цифри в него.

```
Вход: 7812345489
Изход: 5
```
